Durable shared store setup

Phone Safari, desktop Safari, and Chrome must share one live database for seats and preferences. Free jsonblob expires in about 24 hours — too short for an event four weeks out. This Google Apps Script store lasts through August (and beyond), free on your Google account.

3-minute deploy

  1. Open script.google.com signed in as jonray757@gmail.com (or your BSCG Google).
  2. New project → name it RE Shared Store.
  3. Delete any default code. Open re-shared-store.gs from this repo’s tools/ folder, copy all of it, paste into the editor, Save.
  4. Top menu: select function setupOnce → Run. Approve permissions (Google will warn about unverified app — Advanced → Go to project → Allow).
  5. View → Logs — confirm a spreadsheet URL was created (keep that sheet; don’t delete it).
  6. Deploy → New deployment → type Web app:
    • Execute as: Me
    • Who has access: Anyone
    Deploy → copy the /exec URL.
  7. Command center → Outreach → paste into Durable shared store URL → Save integrations → Test shared store (should say OK).
  8. Hard-refresh guest form on phone + desktop. Location Report should say durable Google store.

Open Apps Script Open command center Outreach Open re-shared-store.gs

Why this instead of jsonblob

  • jsonblob free bins were returning 404 after ~1 day — each browser then used its own localStorage (ghost seats).
  • Apps Script + a Google Sheet is free, CORS-friendly, and stable for multi-week events.
  • Same Google account pattern you already use for the Sheets export webhook.

After deploy

Optional: also put the same /exec URL into locations.js as sharedStoreUrl so every device gets it without pasting (requires a git commit + Pages deploy). Outreach localStorage is enough for your machines once each browser has saved integrations.

Guest phones don’t load host integrations — they need sharedStoreUrl in locations.js on GitHub Pages. So after you have a working URL, put it in the repo and push.

Once locations.js has the URL and is pushed, every guest form worldwide uses the durable store automatically.
